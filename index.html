Introduce

대학교에서 처음 프로그래밍 강의를 들었을 때는 낯설고 이해하기 어려운 것 투성이였습니다. 하지만 포기하지 않고 조금씩 이해해나가다 보니, 어느 순간부터 코드 속 로직이 눈에 보이기 시작했습니다. 그때부터 평소 사용하던 포털 사이트나 서비스들을 보며 '이 안에는 어떤 로직이 구현되어 있을까?'라는 궁금증이 생겼고, 자연스럽게 '나는 어떤 서비스를 만들어볼까?'라는 고민으로 이어져 지금의 개발자를 꿈꾸게 되었습니다.

모르던 것을 알게 됐을 때의 짜릿함, 그것이 제가 개발을 계속하는 이유입니다. 대학 프로그래밍 수업에서 낯설기만 했던 코드가 어느 순간 로직으로 읽히기 시작하면서 그 재미를 처음 경험했고, 이후 평소 쓰던 서비스들의 내부가 궁금해지며 직접 만들어보고 싶다는 목표가 생겼습니다. 지금도 꾸준히 공부하며 성장하는 제 모습을 지켜보는 것을 즐깁니다.

Projects

ValuePick — 가치 투자 종목 발굴 서비스 (팀 프로젝트)

GitHub

가치투자 지표 기반 종목 스크리닝 서비스. DART 재무제표, 공공데이터포털 주가, KRX 지수, 한국수출입은행 환율을 매일 자동 수집해 PER·PBR·ROE·Piotroski F-Score 등 투자지표를 계산하고, 다팩터 가중 스코어링으로 저평가 우량주 TOP100을 추천합니다. 개인 투자일지(매수/매도 기록, 손익 관리) 기능을 함께 제공합니다.

담당 기능

  • 종목 상세 조회 API 구현 — 회사 기본정보·최신 시세·투자지표·3개월 시세 추이를 하나의 응답으로 조합하는 Controller-Service 계층을 설계했습니다.
  • 재무제표 조회 API 구현 — DART에서 수집된 재무제표 데이터를 조회할 수 있도록 Controller-Service-Repository 3계층을 신규로 설계했습니다.
  • 관심종목 기능 풀스택 구현 — JWT 인증 연동, 등록/삭제 API, N+1 문제를 해결한 4테이블 조인 쿼리, 전용 페이지(반응형 UI, 낙관적 업데이트)를 구현했습니다.
  • 네이버 금융 뉴스 크롤링 기능 구현 — Jsoup 기반 HTML 파싱, 중복 방지 로직, 스케줄러를 통한 자동 수집 파이프라인을 구축했습니다.

트러블슈팅

  • API 요청 URL 이중 조합 버그 — 관심종목 API 호출이 모두 실패했습니다. 인증 헤더를 자동으로 붙여주는 공통 유틸 함수(authFetch)가 내부적으로 이미 도메인을 붙이고 있었는데, 호출부에서도 도메인을 중복으로 붙여 잘못된 URL이 생성되고 있던 것이 원인이었습니다. 호출부에서 도메인 접두사를 제거해 공통 함수가 해당 책임을 전담하도록 수정했습니다.
  • JWT 인증 정보 복원 시 사용자 ID 누락 버그 — 로그인은 되지만 관심종목 등록 시 사용자를 특정하지 못하는 문제가 있었습니다. JWT 토큰으로 인증 정보를 복원하는 로직이 이메일 존재 여부만 boolean으로 확인하고, 사용자 DTO에는 ID 필드를 채우지 않고 있던 것을 역추적으로 확인했습니다. 엔티티를 직접 조회하도록 변경해 DTO 생성 시 ID를 명시적으로 채우도록 수정했습니다.
